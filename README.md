# 🏚️ Заброшенный Дом (Text Adventure Game)

Простая текстовая приключенческая игра на Python, где вам нужно выбраться из заброшенного дома, найдя ключ и преодолевая препятствия.

## 📖 Описание

Вы оказываетесь в заброшенном доме. Ваша цель — найти выход. Для этого вам потребуется исследовать комнаты, собирать ресурсы (коины), находить предметы (ключ) и следить за своим здоровьем и количеством попыток открыть дверь.

Игра включает систему регистрации пользователя с простой валидацией email и пароля.

## 🚀 Как запустить

1. Убедитесь, что у вас установлен **Python 3.x**.
2. Скачайте или скопируйте код игры в файл, например `game.py`.
3. Откройте терминал или командную строку.
4. Запустите игру командой:

```bash
python qwest.py
```

## 🎮 Геймплей

### Регистрация
При первом запуске вам предложат зарегистрироваться:
- Введите корректный email (должен содержать `@` и `.`).
- Придумайте пароль (минимум 6 символов, подтверждение должно совпадать).

### Основные механики
У вашего персонажа есть следующие характеристики:
- **Здоровье (Health):** Начальное значение 100. Если упадет до 0 — вы проиграли.
- **Попытки (Attempts):** Начальное значение 5. Используются при попытке открыть запертую дверь без ключа.
- **Коины (Coins):** Валюта игры. Нужны для восстановления здоровья.
- **Инвентарь:** Место для хранения найденных предметов.
